# Технотрон

Презентация кейса и главная сайта.

- Презентация: [/tehnotron/](https://ritm0dsgnr.github.io/tehnotron/)
- Главная: [/tehnotron/home.html](https://ritm0dsgnr.github.io/tehnotron/home.html)

## Dev

```bash
npm install
npm run dev
```

Открывать `http://localhost:5173/tehnotron/`.

## Build

```bash
npm run build
```

Сборка в `docs/` для GitHub Pages.
